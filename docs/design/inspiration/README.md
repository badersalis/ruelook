# Inspiration references

Drop anything that inspires you for this product here: screenshots, screen recordings, GIFs, photos, mood images, PDFs, Figma exports. Links and written descriptions go in `../inspiration-board.md` (or just send them in chat).

For each item, say what exactly you like (the gradient, the background pattern, the hover animation, the colours, the type...) and how strongly, from ★ to ★★★. You can also just name effects you'd like to draw from: glassmorphism, mesh gradient, mesh-gradient text, textured text, grain, gradient borders, kinetic type and so on. A file name like `mesh-gradient-hero.png` or `card-hover-tilt.mp4` helps.

These files are **internal inspiration only**. They are never shipped in the app, published, or copied as a whole design. Anything used in the product is recreated, or sourced with a verified licence.
