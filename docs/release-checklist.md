# Release Readiness

- [ ] Scope and acceptance criteria approved
- [ ] Unit/integration/E2E tests reviewed
- [ ] Accessibility and responsive checks reviewed
- [ ] Security findings triaged; critical/high risks resolved or explicitly accepted
- [ ] Database migrations reviewed and rollback considered
- [ ] Environment variables configured outside Git
- [ ] Backups and restore process verified where applicable
- [ ] Monitoring, alerts and logs configured
- [ ] Smoke test and rollback plan documented
- [ ] Known issues and support ownership documented
- [ ] Freelancer approval recorded before production release
